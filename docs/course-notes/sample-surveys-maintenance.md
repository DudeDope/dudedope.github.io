# Sample Surveys website notes

This folder contains website-ready Markdown generated from the complete Classes 1–4 notes.

## Files

- `course-contents.md`: living course landing page; update whenever a lecture is added or renamed.
- `lecture-01-foundations-and-representativeness.md`
- `lecture-02-finite-population-and-srs.md`
- `lecture-03-design-based-estimation.md`
- `lecture-04-confidence-intervals-and-sample-size.md`
- `formula-sheet.md`: cumulative formula sheet; update after every lecture.

## Recommended editing rule

Edit the relevant lecture Markdown file for lecture-specific content. Update only `course-contents.md` and `formula-sheet.md` when the course index or cumulative formula list changes. This keeps each lecture independent and avoids editing one monolithic source file.

The files use YAML front matter and dollar-delimited LaTeX mathematics. They should work with common Markdown-based static-site systems after enabling a math renderer such as KaTeX or MathJax.
