# Course-note rendering audit

Audit date: 2026-08-06

Scope: all 17 public pages in the Sample Surveys and Design and Analysis of Algorithms note collections.

## Findings and corrections

| Rendering defect                                                                                                              | Affected content                                                                                                                                                                                        | Correction                                                                                                                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Display equations were embedded inside prose, so the Markdown math converter emitted inline markup instead of display markup. | All four Sample Surveys lectures and the final Sample Surveys formula-sheet equation; 182 expressions in total.                                                                                         | Moved every display delimiter onto its own line and separated surrounding prose into valid Markdown blocks.                                                                  |
| Vertical bars inside formulas were interpreted as Markdown table separators.                                                  | Sample Surveys Lecture 2, “Ordered and unordered designs”; Sample Surveys Lecture 4, “Margin of error”; DAA Lecture 5, “Duplicates and three-way partitioning”; DAA formula-sheet cardinality notation. | Replaced ambiguous inline bars with named TeX delimiters such as `\lvert`, `\rvert`, `\lVert`, and `\rVert`; moved the Lecture 2 answer formulas into proper display blocks. |
| Liquid `relative_url` filter pipes split Markdown table cells.                                                                | Both course-content tables and the DAA notation table.                                                                                                                                                  | Assigned URLs before each table and referenced the pipe-free variables inside table cells.                                                                                   |
| Markdown consumed escaped set braces in inline mathematics.                                                                   | Set, event, and indicator notation across both subjects, especially Sample Surveys Lectures 1–4 and DAA Lectures 2, 5, 6, and 8.                                                                        | Replaced fragile escaped braces with named TeX delimiters `\lbrace` and `\rbrace`.                                                                                           |
| Emphasis parsing damaged subscripts and summation indices.                                                                    | Sample Surveys Lecture 3, Theorems 3.4 and 3.6 and Lemma 3.8.                                                                                                                                           | Restored `Y_j`, `\operatorname{Var}_{p}`, `\sigma_Y`, `S_Y`, `a_i`, and `\sum_{i<k}` and removed emphasis markers spanning display blocks.                                   |
| Tables could cause the entire note body to become a horizontal scroll container after responsive-table enhancement.           | Course indexes, formula sheets, Sample Surveys Lecture 3, and DAA Lectures 4, 6, and 9.                                                                                                                 | Kept horizontal scrolling on the table itself and explicitly prevented the full reading column from becoming the scroll container.                                           |
| Sample Surveys definitions, theorems, and lemmas were visually indistinct from surrounding prose.                             | All four Sample Surveys lectures; 29 formal statements.                                                                                                                                                 | Wrapped each formal statement in a semantic box and matched its typography and spacing to the DAA callout treatment.                                                         |
| Slide questions and answers were visually over-emphasised by boxes.                                                           | All four Sample Surveys lectures.                                                                                                                                                                       | Removed the blockquotes while preserving the complete question-and-answer text as ordinary reading content.                                                                  |
| Subject descriptions repeated status, institution, topic, maintenance, placeholder, and revision information.                 | Notes landing page and both course indexes.                                                                                                                                                             | Reduced each subject overview to its title, professor, Fall 2026 term, lecture list, and direct formula-sheet access.                                                        |

## Regression checks

- `npm run test:notes:source` checks all 17 Markdown sources for embedded display delimiters, malformed tables, unsafe inline delimiters, damaged TeX, unbalanced math environments, broken public Markdown links, and boxed Sample Surveys questions or answers.
- `npm run test:notes:browser` checks all 17 rendered pages for MathJax errors, raw TeX, accidental or malformed tables, mixed prose/display equations, reading-column escapes, document overflow, unboxed formal statements, and boxed questions or answers.
- The browser audit covers viewport widths of 375, 768, 1024, and 1440 pixels.
